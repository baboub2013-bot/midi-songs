## 🔗 Getting a RAW link

1. Find your song in the table above.
2. Right-click **Download / RAW** and copy the link address, or open it to download the file.
3. Use the link in any tool that supports loading MIDI files from a URL.

RAW links use this format:

```text
https://raw.githubusercontent.com/baboub2013-bot/midi-songs/main/FILE_NAME.mid
```

**Tip:** Spaces and characters such as `&` need URL encoding (for example, a space becomes `%20` and `&` becomes `%26`). The links in the table are already encoded correctly.

## 🎼 About MIDI files

- **Format:** `.mid` (Standard MIDI File).
- MIDI contains note, timing, and other performance data — **not recorded audio** like MP3.
- The sound you hear depends on the MIDI player, instrument, or soundfont you use.
- This repository hosts MIDI files; it does not provide a built-in player or converter.
