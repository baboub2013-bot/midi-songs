## 🔗 How to get a RAW link

1. Open the MIDI file in this repository.
2. Click **Raw** (or **Download raw file**).
3. Copy the resulting URL.
4. Paste it into any compatible MIDI player, converter, or tool that supports loading files from a URL.

RAW URLs follow this pattern:

```text
https://raw.githubusercontent.com/baboub2013-bot/midi-songs/main/FILE_NAME.mid
```

For file names with spaces or special characters, copy the link directly from GitHub to avoid URL-encoding errors.

## 📁 File format

Files are provided as `.mid` (Standard MIDI File). MIDI stores musical note and timing events rather than recorded audio, so playback depends on the instrument or soundfont used.
