## 🔗 Getting a RAW link

1. Find the song above and right-click its **Download / RAW** link to copy the URL.
2. Paste it into a compatible player or converter, or open it to download the MIDI.

RAW URLs follow this structure:

```text
https://raw.githubusercontent.com/baboub2013-bot/midi-songs/main/ARTIST/SONG.mid
```

**Tip:** Spaces and special characters need URL encoding (e.g., `%20` for a space and `%26` for `&`). All links above are already encoded.

## 🎼 About MIDI

MIDI (`.mid`) stores musical notes and timing information, **not recorded audio**. Playback depends on the instruments or soundfont used. This repository hosts MIDI files, not a built-in player.
